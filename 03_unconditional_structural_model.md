# 03 --- Unconditional Structural Utility Model

> Canonical specification (File 3)

# Purpose

This file defines the baseline structural utility specification before
introducing heterogeneity. Every parameter is treated as a scalar
constant. Later files generalize each parameter into a function of
respondent covariates using the FLM framework.

------------------------------------------------------------------------

# Modeling Philosophy

The objective is to estimate economically interpretable utility
primitives rather than directly estimating conditional choice
probabilities.

Choice probabilities are generated by maximizing latent utility under a
nested-logit error structure.

The neural network introduced later estimates structural parameters, not
reduced-form probabilities.

------------------------------------------------------------------------

# Utility Normalization

Only utility differences are identified.

Normalize the deterministic utility of Product 1 to zero:

\[ V_1 = 0. \]

Every remaining intercept is interpreted relative to Product 1.

------------------------------------------------------------------------

# Product 2

Let

\[ Q`\in`{=tex}{0,1} \]

denote randomized Product-2 treatment.

The deterministic utility is

\[ V_2 = `\tilde`{=tex}`\delta`{=tex}\_2 + `\tau`{=tex}\_Q Q. \]

Interpretation:

-   (`\tilde`{=tex}`\delta`{=tex}\_2): baseline preference for Product 2
    relative to Product 1.
-   (`\tau`{=tex}\_Q): direct effect of Product-2 treatment.

------------------------------------------------------------------------

# Product 3

Each Product-3 alternative belongs to the same structural family.

Let

-   \(S\)
-   \(Y\)
-   \(F\)

be entitlement indicators.

The deterministic utility for Product-3 configuration (j) is

\[ V\_{3j} = `\tilde`{=tex}`\delta`{=tex}\_3 + `\kappa`{=tex}\_Q Q +
`\beta`{=tex}\_S S_j + `\beta`{=tex}\_Y Y_j + `\beta`{=tex}\_F F_j +
`\gamma`{=tex}\_S(QS_j) + `\gamma`{=tex}\_Y(QY_j) +
`\gamma`{=tex}*F(QF_j) - `\alpha `{=tex}P*{3j}. \]

Parameter interpretation:

-   (`\tilde`{=tex}`\delta`{=tex}\_3): baseline Product-3 utility.
-   (`\kappa`{=tex}\_Q): Product-2 treatment spillover onto Product 3.
-   (`\beta`{=tex}\_k): main effect of entitlement (k).
-   (`\gamma`{=tex}\_k): interaction between Product-2 treatment and
    entitlement (k).
-   (`\alpha`{=tex}): marginal disutility of Product-3 price.

------------------------------------------------------------------------

# Additive Structure

The maintained specification assumes additive entitlement effects:

-   baseline
-   +S
-   +Y
-   +F

combine linearly.

This produces overidentifying restrictions because some entitlement
bundles appear in both survey arms.

Future robustness analyses may relax this assumption.

------------------------------------------------------------------------

# Arm-Specific Menus

Utilities are evaluated only over the respondent's observed menu.

Arm B:

-   Product 1
-   Product 2
-   baseline
-   S
-   SY

Arm C:

-   Product 1
-   Product 2
-   baseline
-   SY
-   SYF

The pooled menu is never used in an individual's likelihood.

------------------------------------------------------------------------

# Common Price Shifts

Across repeated tasks,

\[ P\_{3jt} = P\_{3j0}+c_t, \]

where (c_t) is a common experimentally assigned price shift.

Therefore

\[ V\_{3jt} = V\_{3j0} - `\alpha `{=tex}c_t. \]

Relative utilities among Product-3 alternatives remain unchanged:

\[ V\_{3jt}-V\_{3kt} = V\_{3j0}-V\_{3k0}. \]

Instead, repeated tasks move the attractiveness of the entire Product-3
family relative to Products 1 and 2.

This observation will be central to the identification argument.

------------------------------------------------------------------------

# Transition to Nested Logit

The deterministic utilities above define the systematic component of
utility.

The next file combines these deterministic utilities with the

probabilities and inclusive values for Arms B and C.
